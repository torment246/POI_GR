# V1 实验

本文件按 `方案.md` 记录第一版完整链路与共享模型选型：POI 文本向量 → RQ-VAE SID → Geohash6 GID → Dedup Final PID → Qwen3-0.6B SFT → Final PID Trie 约束评测。后续论文复现只引用这里已经冻结的数据和共享向量实验，不重复登记；Query 增强等后续向量创新实验单独记录在 [Embedding 优化实验](EMBEDDING_OPTIMIZATION.md)。

## 当前结论

- 北京 2,337,178 条 POI 和 8,790,513 条订单已跑通第一版完整链路。
- 三个文本编码方案已在无 Train 订单泄漏的固定 SFT Validation 10,000 条评测集上重新对齐；BGE-M3 的 Hit@10/20 为 32.39%/40.25%，仍为最优共享文本编码器。V1 下游产物因实验先后顺序仍使用 Qwen3-Embedding-0.6B。
- V1 选择 Qwen `1024×3 / epoch 20` SID，经 Geohash6 和 Dedup 后 Final PID 全局唯一。
- 固定 10,000 条 Validation、Beam=10 下，2.0 epoch checkpoint 的 HR@1/HR@10/NDCG@10 为 45.77%/84.83%/65.99%；尚未运行完整 Validation 或 Test。

### 执行异常与修正

首次按 32,768 条直接向 GPU 分批 add，在 98% 时因 Faiss Flat 数据末次扩容需要同时保留旧缓冲和申请新缓冲而 OOM。第二次改用 CPU Flat 暂存时，在 90% 的主存扩容阶段被系统以退出码 137 终止。两次均未产生不完整召回结果，最终日志覆盖为成功运行日志。

最终采用两批 GPU add：先加入 1,000,000 条，再加入剩余 1,337,178 条；建索引前按“最终索引 + 首批旧缓冲 + 4 GiB 余量”执行 35.83 GiB 显存门禁。该修正不改变 float32 存储、`GpuIndexFlatIP`、精确内积或 Top-20 口径。

### 产物、Case 与结论

- 每个 checkpoint 的产物目录为 `outputs/sid/rqvae/<EXPERIMENT>/evaluations/epoch_<EPOCH>/`，且只包含 `sid_codes.npy`、`sid_manifest.json`、`metrics.json`、`collision_cases.jsonl`；12 组共 48 个文件，无临时文件残留。
- 每组输出 20 个热点碰撞 Case，均因桶大小超过单 Case 的 20 条 POI 上限而标记为截断。文档不记录真实 POI 样本；具体人工核验内容保留在各组 `collision_cases.jsonl`。
- 1024×3 相比 512×3 和 256×3 显著提升 reconstruction cosine、full distinct SID ratio、P99 和 Prefix2/3 类别纯度；但最好的 full distinct SID ratio 仍只有 68.53%，colliding POI ratio 仍为 46.24%。
- 第一层存在稳定的低利用率：256×3、512×3、1024×3 分别只使用 104、169、264 个 L1 Token，对应 40.62%、33.01%、25.78%；容量增大时比例下降，不能据此认为码本已充分使用。
- 监控子集 distinct SID ratio 为 94.52%～98.85%，明显高于全量 26.96%～68.53%。碰撞比例依赖样本规模，23,372 行监控值不能替代 2,337,178 行全量值。
- Prefix3 macro purity 会受到大量 singleton 和小桶影响，不能脱离桶大小与 micro purity 单独解释为语义层级质量。
- checkpoint 指标不单调：256×3 的 full distinct ratio 随 epoch 改善，而 512×3、1024×3 均是 epoch 20 最好；reconstruction cosine 又随容量和训练进度略有改善。因此本实验只汇总，不自动选择 checkpoint，等待人工审核。

- Qwen3-Embedding-4B 在统一数据和精确检索协议下持续弱于 0.6B 和 BGE-M3，不进入后续 Query 增强主线。
- BGE-M3 的 1—2 字 Query Hit@10 仍只有 12.76%，短 Query 是优先分析的稳定瓶颈。
- 后续只使用 2026-07-01—12 Train 正向 Query 修改 POI 向量，固定本实验的 10,000 条 BGE Query 向量、行映射和 Faiss 口径。E1—E4 的实现与结果追加到 [Embedding 优化实验](EMBEDDING_OPTIMIZATION.md)，在得到稳定收益前不启动 RQ-KMeans。
- 本实验未运行完整 Validation 或 Test，也没有训练或微调任何 Embedding 模型。
